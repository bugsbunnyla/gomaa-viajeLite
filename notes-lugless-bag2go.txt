How to Install
iPhone / iPad
Unzip and upload to any web host (or open index.html in Safari via local server)
Tap Share → Add to Home Screen
Launches full-screen like a native app with burgundy status bar
Android
Open in Chrome
Tap ⋮ → Add to Home screen
Installs with splash screen and native launcher icon
Web
bash
cd gomaa-bag2go
npx serve . -l 8080
# open http://localhost:8080
